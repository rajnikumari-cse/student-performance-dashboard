
# 📊 Student Performance Dashboard

A responsive web-based dashboard designed to display student academic performance, attendance, subject-wise marks, and performance status in one place.

## 🌟 Features

- **Performance Summary:** Displays total students, average marks, attendance, and pass percentage.
- **Subject Performance:** Visual progress bars for HTML & CSS, Python, SQL, and Data Analytics.
- **Student Details:** Displays student names, courses, marks, attendance, and performance status.
- **Search Functionality:** Search student records by name or course.
- **Performance Filter:** Filter students by Excellent, Good, or Needs Improvement.
- **Performance Statistics:** Automatically calculates the number of students in each performance category.
- **Contact Form:** Validates the form and displays a confirmation message on the page.
- **Responsive Design:** Layout adjusts for desktop, tablet, and mobile screens.
- **Modern UI:** Sidebar navigation, summary cards, progress bars, and status indicators.
- **Current Date:** Displays the current date automatically.

## ⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` in your browser.
5. Use the search box and performance filter to explore student records.

## 🔍 JavaScript Functionality

JavaScript is used to:

- Search student records dynamically.
- Filter students based on marks.
- Calculate performance category counts from the sample records.
- Display the current date.
- Validate the contact form and show a confirmation message.
- Highlight the active navigation link.

**Note:** The contact form does not send messages to a server or email. The dashboard currently uses sample data and does not have a database or backend integration.

## 🎯 Project Objective

The objective of this project is to present academic information in a clear, organized, and user-friendly dashboard while demonstrating frontend development skills and basic data visualization concepts.
